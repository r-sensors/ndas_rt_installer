# NDAS Installer
Version: 2.0

## Инструкция по использованию
1. После первичной установки debian на beagle bone запустить команду, находясь в директории /var/lib/cloud9:
```
git clone https://github.com/r-sensors/ndas_rt_installer.git
```
2. Зайти в директорию `cd ndas_rt_installer` и выполнить 
`sudo ./autoinstall` 
3. Следовать инструкциям установщика, заполнить все поля.

## Выборочная установка
Для выборочной установки запустите скрипт `install.sh` командой 
```bash
sudo ./install.sh
```
